Connect it in a minute

One remote URL for clients that speak HTTP, and a small command for clients that only start local programs. Both reach the same index.

Remote URL

Streamable HTTP, no authentication. Paste it wherever a client asks for an MCP server URL.

https://mcp.10ml.com/mcp

npx (Node.js 18+)

For Claude Desktop, Cursor, Goose and other stdio clients.

npx -y @10ml/perfume-finder-mcp

@10ml/perfume-finder-mcp on npm

uvx (Python 3.10+)

The same server from PyPI, no install step.

uvx perfume-finder-mcp

perfume-finder-mcp on PyPI

Claude

claude.ai and the desktop app: Settings, Connectors, Add custom connector, then paste the URL. Claude Code:

claude mcp add --transport http perfume-finder https://mcp.10ml.com/mcp

ChatGPT

Settings, Apps and Connectors, Advanced settings, turn on Developer mode, then Create a connector with the URL above and no authentication.

Cursor

One click, or add this to ~/.cursor/mcp.json.

{
  "mcpServers": {
    "perfume-finder": { "url": "https://mcp.10ml.com/mcp" }
  }
}
Add to Cursor

VS Code (Copilot agent mode)

One click, or run MCP: Add Server and paste the URL.

{
  "servers": {
    "perfume-finder": { "type": "http", "url": "https://mcp.10ml.com/mcp" }
  }
}
Install in VS CodeVS Code Insiders

Windsurf

Add to ~/.codeium/windsurf/mcp_config.json.

{
  "mcpServers": {
    "perfume-finder": { "serverUrl": "https://mcp.10ml.com/mcp" }
  }
}

Cline

MCP Servers, Remote Servers, name perfume-finder, or edit the settings file.

{
  "mcpServers": {
    "perfume-finder": {
      "type": "streamableHttp",
      "url": "https://mcp.10ml.com/mcp",
      "disabled": false
    }
  }
}

Goose

Extensions, Add custom extension, then paste the command, or add it to the config file.

extensions:
  perfume-finder:
    name: 10ML Fragrance Index
    type: stdio
    cmd: npx
    args: ["-y", "@10ml/perfume-finder-mcp"]
    enabled: true
    timeout: 300

Claude Desktop (stdio)

Settings, Developer, Edit Config.

{
  "mcpServers": {
    "perfume-finder": {
      "command": "npx",
      "args": ["-y", "@10ml/perfume-finder-mcp"]
    }
  }
}

Gemini CLI

Installs the extension straight from the repository.

gemini extensions install https://github.com/10ml-com/perfume-finder-mcp
